    In plain words: wall time is how long the run took. Model calls and tokens show how much the local AI model was used (tokens ≈ words read/written; a GPU profile reasons in more steps and sends more frames, so it reads more) — a cloud service would bill exactly this, which is cloud API would have billed; here it cost only the electricity shown next to it. Frames processed / skipped show that the system looks closely only where something happens and safely skips the rest. Tool calls · critic count the investigation steps and how often the adversarial critic double-checked the conclusion. Edge / cloud placement lists every computation and confirms it stayed on this device. Security counts permission checks and prompt-injection flags on untrusted text such as transcripts.
